# 人生ゲーム税務台帳

人生ゲームの進行中に、日本の税制（所得税・住民税・復興特別所得税・一時所得・株式・不動産・相続税相当ほか）を
現実の金額の「1/スケール」に換算して自動計算する、ブラウザ上の台帳アプリです。

- プレイヤー管理、イベント入力（給与・一時所得・配当・非課税・支出・ご祝儀）
- 株式市場（5銘柄・ニュース・配当）、不動産と住宅ローン、お宝（ゴール時に決算）
- 年金の自動支給、借金利息、ゴール精算（資産課税）、純資産ランキング
- スケールの変更（過去の操作から台帳を再計算）、元に戻す

## 使い方
`index.html` をブラウザで開くだけで動きます（インストール不要）。

## データの保存について
- 操作のたびに、そのブラウザ内に自動保存されます（別のブラウザ・端末・シークレットモードには引き継がれません）。
- 画面上部の「書き出す」でバックアップ文字列を取り、「読み込む」で復元できます。こまめなバックアップをおすすめします。
- 全データを消して最初から始めるときは「新規ゲーム」を押してください。
